# 即刻一键分发

在即刻网页版（web.okjike.com）每条动态的操作栏加一个「分发」按钮，一键把帖子发到 **X、微博、豆瓣**。架构继承自「X 一键分发」插件（x-distributor）：不调平台 API，打开各平台官方发布页后注入脚本自动填内容，你确认后手动点发布（或开启自动点击）。

## 安装

1. 克隆或下载本仓库
2. 打开 Chrome，地址栏输入 `chrome://extensions`
3. 右上角打开「开发者模式」
4. 点「加载已解压的扩展程序」，选择本仓库目录
5. 确保你已在同一 Chrome 里登录：**web.okjike.com、x.com、weibo.com、www.douban.com**

## 使用

1. 打开 https://web.okjike.com 的动态/个人主页，每条帖子操作栏最左侧会出现「分发」（黄色纸飞机图标）
2. 点击后弹出发布确认窗：可改正文、勾选平台（X/微博/豆瓣）、附原帖链接、带话题标签
3. 点「开始分发」→ 扩展打开各平台发布页（自动归入一个黄色标签组），自动上传原画质图片、填正文
4. 默认需要你到各标签页**手动点发布**；勾选「自动点击发布」可全自动
5. 发布完成后回到小窗点「关闭全部发布页」

### 找不到「分发」按钮时

按钮理论上不会消失：页面回前台、DOM 变化时都会立即重新注入。若仍找不到（如扩展刚重载、页面结构改版），**点浏览器工具栏的本扩展图标**，立即强制恢复所有按钮（图标上会闪一个 ✓）。在非即刻页面点图标会直接打开即刻首页。

## 平台细节

| 平台 | 入口 | 图片上限 | 正文限制 |
|------|------|---------|---------|
| X | x.com/compose/post | 4 张 | 280 units（中文约 140 字，超长可自动截断） |
| 微博 | weibo.com 首页发布框 | 9 张 | 超 140 字自动折叠为「展开」，可直接发 |
| 豆瓣 | douban.com 首页「我说」广播框 | 9 张 | 基本无限制 |

- 即刻图片自动取**原画质**（七牛 imageMogr2 2400 档，实测比列表缩略图大一个量级）
- 长帖在列表页被折叠时会先自动展开再提取全文
- 即刻视频帖：暂以文字形式分发（网页版视频是流式播放，直链抓取不稳定）

## 验证状态（2026-09-23）

- ✅ 即刻端全链路实测：按钮注入、正文/图片/话题/作者/原帖链接提取
- ✅ 2026-09-23 修「分发后回来找不到按钮」：根因是分发时即刻页在后台、setInterval 被 Chrome 节流到分钟级，React 重渲染丢按钮后补不回来。现改为 visibilitychange/focus + MutationObserver 即时补注入，另加工具栏图标兜底（点击强制恢复）
- ⚠️ X / 微博 / 豆瓣 adapter 未在登录态下实测（选择器带多级兜底）。若某平台没填上内容，页面顶部会出现彩色状态条说明原因——把状态条文字（或 F12 Console 里 `[即刻分发]` 日志）[提 issue](https://github.com/qishuai6/jike-distributor/issues) 反馈即可

## 目录结构

```
manifest.json            MV3 配置
content/okjike.js        即刻页注入：按钮 + 帖子提取（选择器 2026-09-22 实测）
background/service.js    消息路由 + 平台表 + 3 个自包含 adapter（executeScript 注入用）
tabs/publish.html/js/css 发布确认窗（原生 JS，无构建链）
icons/                   图标
```

## 说明

- 本扩展为个人开发的非官方工具，与即刻 / X / 微博 / 豆瓣均无关联
- 不调用任何平台 API，也不收集任何数据；发布动作发生在各平台官方页面里
- 平台页面结构改版可能导致选择器失效，届时欢迎提 issue
